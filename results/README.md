# Released result summaries

`openclip/summary.json` contains the primary Frozen OpenCLIP six-transfer aggregate used for the main table. `analysis/` contains compact summaries used for selector reliability, calibration budgets, and stability analyses, and the temporal controls reported in openclip_temporal_ablation_summary.json. The SHA-256 files preserve provenance for the original saved reports.

Raw videos, frozen feature tensors, trained adapter checkpoints, and full per-run caches are intentionally excluded from Git. They should be distributed separately as a release archive only after verifying dataset licensing and storage permissions.
